# 重庆三峡科技大学校园网自动登录

## 它做什么

`CampusNetAutoLogin.exe` 启动后直接向校园网认证服务器发送登录请求：

- 没登录 → 服务器接受，完成认证；
- 已经在线 → 服务器返回“已在线”，没有副作用；
- 开机时网络还没就绪 → 每 2 秒重试一次，最多 20 次，网络一好就立刻登录；
- 登录成功后，可等待 30 秒自动开启 Windows 电脑移动热点。

## 开关界面

双击 exe（不在启动文件夹里时），会打开中文控制窗口，可以：

- 填写并保存账号密码；
- 勾选“登录成功后自动开启电脑移动热点（等待 30 秒）”；
- 查看“开机自启：已开启 / 已关闭”；
- 开启 / 关闭开机自启；
- 立即登录测试。

任何操作弹窗点“确定”后，程序会自动退出，不会留在后台。

## 开机自启

点击“开启开机自启”，程序只会把 **exe 本身**复制到 Windows 启动文件夹。

账号密码和日志保存在：

```
%APPDATA%\CampusNetAutoLogin\
```

不会再把 ini 或 log 放进启动文件夹，因此 Windows 开机时不会再额外打开文件窗口。

## 停止使用

- 双击 exe → 点“关闭开机自启”；
- 或打开启动文件夹（`Win+R` → `shell:startup`），删除里面的 exe；
- 或在任务管理器“启动应用”中禁用。

如果旧版本曾在启动文件夹里留下 `CampusNetAutoLogin.ini` 或 `.log`，点一次“关闭开机自启”会自动清理。

## 移动热点

勾选界面里的移动热点选项后，程序会在登录成功约 30 秒后调用 Windows 自带的移动热点功能。

前提：电脑的无线网卡驱动支持 Windows“移动热点”，并且系统设置里已经配置好热点名称和密码。

## 日志

运行记录在：

```
%APPDATA%\CampusNetAutoLogin\CampusNetAutoLogin.log
```

遇到问题把最后几行发出来即可排查。

> 注意：账号密码以明文保存在 `%APPDATA%\CampusNetAutoLogin\CampusNetAutoLogin.ini`，不要把这个文件发给别人。
